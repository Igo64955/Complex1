# Complex1

Ein einfaches C++-Konsolenprogramm, mit dem komplexe Zahlen in eine Liste eingetragen und später in eine Datei gespeichert werden können.

## Bauen

```bash
g++ -std=c++17 -O2 -Wall -Wextra -pedantic /home/runner/work/Complex1/Complex1/main.cpp -o /home/runner/work/Complex1/Complex1/complex_list
```

## Starten

```bash
/home/runner/work/Complex1/Complex1/complex_list
```

Im Menü können komplexe Zahlen hinzugefügt, angezeigt und in eine Datei gespeichert werden.
